## Phase I award size

- Navy SBIR Phase I: $200,000 base (6 months) plus a $115,000 option (6 months); Phase II up to $2,000,000.
- Source: the [BW&CO Release 2 summary](https://www.bwcoconsulting.com/programs/dow-sbir-sttr-release-2), which attributes it to the Navy Release 2 instructions. **Not yet confirmed against the instructions PDF.**

## Still to confirm from the instructions

These could not be read automatically and must be checked in the PDFs above:

- Proposal volumes (cover sheet, technical volume, cost volume, commercialization report, supporting documents, fraud/waste/abuse training) and which are required.
- Technical volume page limit, font and format rules, and required sections.
- Any FY27 changes, such as a cap on proposals per company, foreign ownership or disclosure forms, and CMMC affirmations.
- Registration prerequisites (SAM.gov UEI, DSIP account) and how long they take.

Every Navy topic page in this release lists a projected CMMC level of **Level 2 (Self)**, which means a NIST SP 800-171 self-assessment posted in SPRS.
